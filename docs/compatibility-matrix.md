# Compatibility matrix (DD Hub integration status)

Generated by `tools/gen_matrix.py` from `ddhub/data/*.json`. Do not edit by hand.

Three different things are kept apart here:

1. **Upstream status** - what the emulator projects themselves report (sources and dates: [research/compatibility.md](research/compatibility.md), accessed 2026-11-18).
2. **DD Hub integration** - which launch methods the hub knows how to find, configure and start.
3. **Tested here** - what was actually played in a recorded test. Only two rows have that, and only in the build container (no GPU, no audio, no physical controller) - **nothing has been tested on your hardware yet**.

Priority assumes a mid-range Windows/Linux PC; check per-title lists for 3D-era systems.
